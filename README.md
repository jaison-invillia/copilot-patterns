# Copilot Patterns

Repositório centralizado para dados do GitHub Copilot, incluindo prompts reutilizáveis, chatmodes, instruções, arquitetura de projetos, templates de issues e diretrizes de code review.

## 📁 Estrutura do Repositório

```
copilot-patterns/
├── .copilot/               # Configurações do GitHub Copilot Spaces
├── prompts/                # Prompts reutilizáveis
├── chatmodes/              # Configurações de chat modes customizados
├── instructions/           # Instruções para o Copilot
├── architecture/           # Templates de arquitetura de projetos
├── templates/              # Templates de issues e PRs
│   ├── issues/            # Templates de issues
│   └── pull_requests/     # Templates de pull requests
└── guidelines/             # Diretrizes de code review
```

## 🚀 Como Usar

### Prompts Reutilizáveis

Os prompts estão organizados na pasta `prompts/` por categoria. Cada arquivo contém prompts especializados para diferentes cenários de desenvolvimento.

**Exemplo de uso:**
```
Use o prompt em prompts/code-generation/api-endpoint.md para criar novos endpoints
```

### Chat Modes

Configurações de chat modes personalizados estão em `chatmodes/`. Estes definem comportamentos específicos do Copilot para diferentes contextos.

### Instructions

Instruções detalhadas para o Copilot estão em `instructions/`, organizadas por tipo de tarefa ou tecnologia.

### Arquitetura

Templates e padrões de arquitetura de projetos estão em `architecture/`, servindo como referência para estruturação de novos projetos.

### Templates

Templates para issues e pull requests estão em `templates/`:
- `templates/issues/`: Templates de issues para diferentes tipos de tarefas
- `templates/pull_requests/`: Templates de PRs para diferentes tipos de mudanças

### Guidelines

Diretrizes de code review e boas práticas estão em `guidelines/`.

## 🔧 GitHub Copilot Spaces

Este repositório está configurado para uso com GitHub Copilot Spaces. As configurações estão em `.copilot/`.

## 📝 Contribuindo

Para adicionar novos padrões:

1. Escolha a pasta apropriada para seu conteúdo
2. Siga o formato dos arquivos existentes
3. Adicione documentação clara e exemplos
4. Submeta um PR com suas alterações
