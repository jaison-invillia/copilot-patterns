## 🎯 O que são Instructions?

Instructions são diretrizes detalhadas que orientam o GitHub Copilot sobre como:

- Gerar código seguindo padrões específicos
- Aplicar convenções de nomenclatura
- Estruturar arquivos e diretórios
- Implementar funcionalidades específicas
- Seguir boas práticas de segurança e performance

## 📝 Formato das Instructions

Cada arquivo de instruction deve conter:

1. **Objetivo**: O que a instruction cobre
2. **Padrões**: Convenções e padrões a seguir
3. **Exemplos**: Código de exemplo
4. **Anti-padrões**: O que evitar
5. **Checklist**: Verificações importantes

## 🔧 Como Usar

1. Identifique a tecnologia ou tarefa
2. Consulte o arquivo de instruction correspondente
3. Aplique as diretrizes ao seu código
4. Use as instruções em prompts ao Copilot
