# Prompts Reutilizáveis

Esta pasta contém prompts reutilizáveis organizados por categoria.

## 📂 Estrutura

```
prompts/
├── README.md                    # Este arquivo
├── code-generation/            # Prompts para geração de código
├── refactoring/                # Prompts para refatoração
├── testing/                    # Prompts para testes
├── documentation/              # Prompts para documentação
└── debugging/                  # Prompts para debugging
```

## 🎯 Como Usar

1. Navegue até a categoria desejada
2. Escolha o prompt apropriado para sua tarefa
3. Copie e adapte o prompt conforme necessário
4. Use com GitHub Copilot Chat

## ✨ Exemplos de Prompts

### Geração de Código
- Criar API endpoints REST
- Implementar validações
- Criar modelos de dados

### Refatoração
- Melhorar performance
- Aplicar padrões de design
- Reduzir código duplicado

### Testes
- Criar testes unitários
- Criar testes de integração
- Criar mocks e stubs

### Documentação
- Documentar APIs
- Criar READMEs
- Gerar comentários de código

### Debugging
- Identificar bugs
- Sugerir correções
- Analisar logs

## 📝 Template de Prompt

Ao criar novos prompts, siga este template:

```markdown
# [Nome do Prompt]

## Objetivo
[Descrição do objetivo]

## Contexto
[Informações de contexto necessárias]

## Prompt
[Texto do prompt]

## Exemplo de Uso
[Exemplo de como usar]

## Resultado Esperado
[Descrição do resultado esperado]
```
